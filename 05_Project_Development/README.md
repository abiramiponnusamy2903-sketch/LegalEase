# Phase 5: Project Development

## Project Title

**LegalEase – AI-Powered Legal Document Generator**

## Development Overview

LegalEase was developed as a web-based application that uses Generative AI to assist users in creating structured legal document drafts.

The application consists of a Streamlit frontend, FastAPI backend, and Google Gemini integration.

## Technology Stack

- Python
- Streamlit
- FastAPI
- Google Gemini
- Pydantic
- Requests
- Git and GitHub
- Visual Studio Code
